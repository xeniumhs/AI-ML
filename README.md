## AI, Machine Learning & RAG

This repository contains documentation, notes, experiments, and projects related to **Artificial Intelligence (AI), Machine Learning (ML), and modern AI systems**. It represents my learning journey as I explore different concepts and gradually apply them to practical problems.

The repository covers fundamental and advanced topics such as **data preprocessing, supervised and unsupervised learning, model training, evaluation, optimization, neural networks, deep learning, and AI algorithms**. The goal is to understand not only how individual techniques work, but also how they can be combined to create complete and practical AI-powered systems.

A major part of this learning journey is **Retrieval-Augmented Generation (RAG)**. RAG combines information retrieval with generative AI by retrieving relevant information from external knowledge sources and providing it to a language model as context before generating a response. This helps AI systems produce more relevant and knowledge-grounded answers while reducing their dependence on information stored within the model itself.

The repository will also cover different **types and approaches to RAG**, including **Naive RAG, Advanced RAG, Modular RAG, Graph RAG, and Agentic RAG**. These approaches explore different ways of handling document processing, retrieval, reranking, context management, knowledge graphs, and agent-based reasoning. Understanding these variations will help in choosing the right architecture for different real-world applications.

The ultimate goal is to bring these concepts together and build a **larger AI/ML project that incorporates multiple techniques**, rather than treating each concept as an isolated topic. This repository will therefore serve as both a learning record and a foundation for developing more advanced AI applications through **learning, experimentation, integration, and practical implementation**.
